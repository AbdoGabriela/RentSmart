# RentSmart

Trabalho da disciplina Algorithmic Thinking & Introduction to Object-Oriented Programming (UniFECAF).

Programa em Python que calcula o orçamento de aluguel da R.M Imóveis e gera um arquivo CSV com os 12 primeiros meses.

Feito por Gabriela Marina Abdo - ADS.2NA

## Como rodar

1. Ter o Python instalado (usei a versão 3.11)
2. Baixar ou clonar este repositório
3. Abrir a pasta do projeto no terminal ou no VS Code
4. Rodar o comando:

```
python main.py
```

5. Responder as perguntas no terminal
6. No final aparece o orçamento na tela e o arquivo `projecao-12-meses.csv` é criado na pasta

Se o comando `python` não funcionar, tente `py main.py`.

## Arquivos

- `main.py` - programa principal (perguntas e validação)
- `classes.py` - classes Imovel, TaxaContratual e Orcamento
